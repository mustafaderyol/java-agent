cURL Live REQ / RES (Dynamic Probe) Guide
Terminal commands to start, inspect, stream, and stop live payload capture
▶️ 1. Start Live Probe for a Specific Method

Captures real runtime arguments and return values of the targeted method for the specified duration (e.g. 60s) and quota (e.g. 20 requests): 

curl -X POST http://localhost:9876/probe/start \
  -H "Content-Type: application/json" \
  -d '{
    "className": "com.mderyol.testapp.TestApplication$PaymentService",
    "methodName": "processPayment",
    "durationSeconds": 60,
    "maxCaptures": 20
  }'
📦 2. Start Multiple Independent Services (Batch Probes)

To monitor multiple independent distinct services simultaneously with a single cURL command, use the probes list: 

curl -X POST http://localhost:9876/probe/start \
  -H "Content-Type: application/json" \
  -d '{
    "probes": [
      {"className": "com.mderyol.testapp.TestApplication$PaymentService", "methodName": "processPayment"},
      {"className": "com.mderyol.testapp.TestApplication$UserProfileService", "methodName": "getUserDetails"}
    ],
    "durationSeconds": 60,
    "maxCaptures": 20
  }'
⚡ 3. Wildcard (*) Pattern for Entire Package 
curl -X POST http://localhost:9876/probe/start \
  -H "Content-Type: application/json" \
  -d '{"className": "com.mderyol.testapp.*", "methodName": "*", "durationSeconds": 30, "maxCaptures": 50}'
📊 4. Inspect Status & Live Stream Logs 
# View active probe rules, remaining seconds and quotas:
curl http://localhost:9876/probe/status

# Live stream captured payloads from terminal:
tail -f agent-logs/probe-capture*.log
⏹️ 5. Stop Live Probes 
# Stop a specific method early:
curl -X POST http://localhost:9876/probe/stop \
  -H "Content-Type: application/json" \
  -d '{"className": "com.mderyol.testapp.TestApplication$PaymentService", "methodName": "processPayment"}'

# Stop all active probes immediately:
curl -X POST http://localhost:9876/probe/stop \
  -H "Content-Type: application/json" \
  -d '{"all": true}'
